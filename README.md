# 👋 Hi, I'm Antonio Mauro Galiano

### Senior Robotics Engineer | ROS/ROS2 & Embedded Systems Specialist | AI-Driven Full-Stack Development

I’m a **Robotics Software Engineer** with over a decade of experience designing and developing end-to-end solutions for ground, aerial, and marine robotics.  
My work spans **ROS/ROS2 software architecture**, **embedded firmware**, and **AI-assisted development**, with a focus on reliability, modularity, and scalable deployments.

- 🚀 **Core expertise:** ROS/ROS2, C++, Python, Computer Vision, Perception, Navigation, and Sensor Fusion  
- 🧩 **Systems integration:** Embedded boards, LIDAR, ArduPilot, and Mission Planner connected to ROS/ROS2  
- 🐳 **Deployment:** Fully Dockerized pipelines with automated build, testing, and CI/CD deployment environments  
- 🤖 **AI-assisted development:** Advanced use of ChatGPT and Cursor for refactoring, debugging, and code generation  
- 🌍 Based in Bologna, Italy  
- 🤝 Open to collaboration on open-source robotics and ROS2 projects
